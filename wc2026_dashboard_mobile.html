📖 What do the columns mean?
👉 ENTER THIS = the only number you type into SuperBru — the score that earns the most points on average (deliberately safer than the flashy score). Most likely = our best guess at the actual result, for INFO only — sometimes it differs from ENTER THIS, and that's fine, still enter the green one. Confidence = how bankable the pick is: Banker (strong favourite) / Solid / Coin-flip (toss-up). 1X2 = each side's chance to win (and the draw), model + bookmakers. xG = expected goals. Over2.5 = chance of 3+ goals. BTTS = both teams score. exp pts = the pick's average points (max 3 = exact). Safe vs Bold (button above) = Safe shows the green ENTER THIS scores; Bold swaps them to gamble on the exact result — only when you're chasing. Adv% (group tables) = chance of reaching the knockouts across 4,000 simulated tournaments; group xPts are simulation averages, not real table points. Row shading = how bankable the game is.

How it works & how to drive it

Model = engine v2 (Fable recut): dynamic Elo + rolling form + incremental attack/defence ratings + Elo momentum, recency-weighted (12-year half-life) → blended logistic / twin-Poisson outcomes with a fitted per-class calibration (avg T=0.98) and Dixon-Coles-corrected twin-Poisson scorelines (ρ fitted by maximum likelihood, =-0.03). Selected by backtest against the previous engine: more SuperBru points on 5 past tournaments (292.0 vs 278.0 under the official scoring rules — also beating the "2-1 favourite" heuristic, which the old engine never did), better calibration, more exact scores; gradient boosting and xG features were tested and rejected. Scoring implements the official SuperBru rules: 3 exact / 1.5 close / 1 result, close = 1 goal out or 2 goals out with the correct goal difference; knockout picks are optimised on the post-extra-time score (a shootout is scored as a draw). The match picks (section 2) use pure form/Elo; an EA Sports FC 26 squad-strength prior is applied only to the title odds, group standings and bracket — back-tests on 5 past tournaments showed it sharpens the champion call but slightly hurt match-level scoring. The SuperBru pick is the scoreline that maximises expected SuperBru points (3 exact / 1.5 close / 1 result) — usually a safe, common score; the vs 2-1 fav column flags when it deliberately deviates from the strong "2-1 to the favourite" baseline (green = trust the edge, amber = marginal). On accuracy: in back-testing the model's match-outcome calibration (1X2 log-loss ≈ 0.98) already matches the bookmaker benchmark, so the bookmakers' odds are shown for interest and late team-news only — they add little to the model's accuracy. Bookmaker odds are shown as information only — this is a for-fun forecaster, not a betting tool.
